# resumo-do-lab
Este repositório contem um resumo das loções aprendidas durante o desenvolvimento do lab na DIO
Durante o desenvolvimento do lab no dio foi possível obter os conhecimentos básicos de computação em nuvem, tais como: criação de conta no microsoft azure, personalização do menu inicial e até mesmo as categorias, passando por rede, armazenamento, computação, e outros mais nos quais vamos nos aprofundar no decorrer do curso, a versão previa foi algo que foi visto rapidamente até porem nada muito aprofundado, mas no geral a computação em nuvem é uma das arêas mais importantes para qualquer programador, desenvolvedor ou até empresa que queira armazenar seus dados, precisa-se ter conhecimento em computação em nuvem para que se tenha uma segurança de que não perdera seus dados.
